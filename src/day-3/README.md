# Day 3 — Learning Journey

## What I practiced on Day 3

- Filtering invoice records by customer.
- Combining search and status filters in one memoized function.
- Calculating KPI cards from the filtered invoice set.
- Building responsive controls for search, status, and customer selection.
- Keeping derived data separate from the source invoice records.

## What I built

- A customer-focused invoice view with a searchable table.
- Status and customer filters that work together.
- Summary cards for total, paid, and overdue amounts.
- A learning journal page documenting the Day 3 concepts.

## Problem I solved

The first version kept an unused status filter and unnecessary table features. The page now uses a simpler table and a working status filter.
